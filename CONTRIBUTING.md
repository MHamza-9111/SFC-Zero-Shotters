## GitHub Authorship Rule

1. **Honest Contribution History**: Never fake git commit authorship or pretend commits were made by accounts other than the active authenticated user.
2. **Commit Conventions**: Use conventional commit prefixes:
   - `chore`: Infrastructure and repository structure initialization
   - `docs`: Documentation updates and SRS mapping
   - `data`: Dataset generator and raw/cleaned data handling
   - `python`: Data science, analytics, and Python pipeline modules
   - `spark`: PySpark big data jobs, SQL queries, MLlib models, dual pipeline
   - `src`: Application backend, REST API routes, web services
   - `tests`: Automated unit and integration test additions
3. **Module Ownership Headers**: Every source file must include module header docstrings identifying responsible authors and software duties.
